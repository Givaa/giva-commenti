# Commenti di giovannirapa.com

Qui vivono i commenti agli articoli del blog di [giovannirapa.com](https://giovannirapa.com), tramite
[giscus](https://giscus.app): ogni articolo è una discussione nella categoria *Announcements*, creata
automaticamente al primo commento.

Per commentare vai sull'articolo e premi "Carica i commenti". `giscus.json` permette di usare questo
repository solo dal sito (e da localhost per le prove).
